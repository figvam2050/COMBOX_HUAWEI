# COM-Box (Huawei ESM) — Прошивка конвертера BMS RS485 → CAN (Deye V3.3 / DY001)

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

> **⚠️ Це окремий спеціалізований проєкт для роботи з акумуляторними батареями Huawei ESM** (ESM-48100A1/B1/B3/U2, ESM-48150B1 тощо).
> Прошивка PlatformIO для мікроконтролера **GD32F305RCT6** (Cortex-M4F, 256K Flash, 96K RAM), яка виконує роль інтелектуального шлюзу та координатора безпеки між акумуляторним банком **Huawei ESM (15S LiFePO4)** та гібридним сонячним інвертором **Deye** (протокол **Deye PCS CAN V3.3 / `DY001`**, Lithium Mode 00, 500 кбіт/с).

RS485-бік прошивки реалізує протокол Modbus RTU для швидкісного опитування акумуляторів Huawei ESM (конфігурація для банку з 1 або 2 модулів: адреси `0xD6` = 214 та `0xD7` = 215, динамічна підтримка роботи як з одним, так і з двома блоками, швидка серія з 3-х ключових FC03-запитів телеметрії, цикли/ємність/аварійні слова `0x0042–0x004A`, по-коміркова телеметрія 15 комірок `0x0022..0x0030`, повільний цикл моніторингу та синхронізована видача в CAN після агрегації).

## Швидкий старт (розробка та збірка)

```bash
git clone https://github.com/figvam2050/COMBOX_HUAWEI.git
```

1. **VS Code:** `File → Open Folder…` → обрати папку `COMBOX_HUAWEI`. Встановіть рекомендоване розширення **PlatformIO IDE** (за пропозицією з [`.vscode/extensions.json`](.vscode/extensions.json)).
2. **Збірка:** у терміналі виконати:
   ```bash
   pio run
   ```
   Обидва варіанти збірки (автономний `genericGD32F305` та `genericGD32F305_app` під заводський завантажувач з міткою `G5RC`) збираються одночасно за один прогін.
3. **Готові бінарні образи:** `compiled_firmware/firmware.bin|.hex` (standalone) та `compiled_firmware_app/` (під bootloader). Прошивка через ST-Link:
   ```bash
   pio run -t upload
   ```
4. **Діагностика шини:**
   - Пасивний RS485-сніфер батарейної лінії: `tools/rs485_sniff.py`
   - Зовнішній CAN-сніфер для ESP32 / Arduino Nano: папка `can_sniffer/`
5. **Еталон знань Deye:** `DEYE_CAN_RS485_BASE.md` містить повну специфікацію протоколів CAN (Pylontech v2.0.6) та Modbus RTU інвертора.
6. **Готові прошивки:** папка `compiled_firmware/` містить скомпільовані бінарні файли `firmware.bin` та `firmware.hex` для швидкої прошивки через ST-Link (адреса `0x08000000`).

## Хто що: простий опис системи

**Що це за коробка:** COM-Box — це апаратний перекладач та захисний координатор між промисловими акумуляторами Huawei ESM та гібридним інвертором Deye. Акумулятори Huawei розмовляють по шині RS485 протоколом Modbus RTU, а інвертор приймає швидку шину CAN стандарту Deye PCS CAN V3.3 (`DY001`). Коробка забезпечує їхнє узгодження, виконує агрегацію паралельних блоків у єдину віртуальну батарею та захищає акумулятори від аварійних режимів.

**Що прошивка робить автоматично в циклі:**
1. **Самоадресація та виявлення модулів:** батареї Huawei ESM з'єднуються кабелем RJ45 ланцюжком (COM_IN / COM_OUT). На останньому модулі встановлюється штатний CAN-термінатор 120 Ом (піни 7/8). Завдяки цьому модулі автоматично розподіляють адреси `0xD6, 0xD7` (214, 215). Підтримується гаряче підключення та робота як з двома, так і з одним акумулятором.
2. **Опитування телеметрії:** коробка послідовно опитує кожен активний блок швидкою серією з 3-х ключових Modbus FC03-запитів (~1 с):
   - `0x0000 × 7`: напруга шини, напруга модуля, струм зі знаком, SOC, SOH, екстремуми температур;
   - `0x0042 × 9`: лічильники циклів (`0x0042–0x0043`), ємності (`0x0044–0x0045`) та апаратні аварії й попередження (`0x0046–0x004A`);
   - `0x0022 × 15`: точні напруги всіх 15 окремих комірок (у мВ).
   - **Повільний цикл (раз на ~5 циклів кожного модуля):** додатково по черзі опитуються `0x0012 × 15` (температури 15 комірок), `0x0101 × 15` (версії/кількість комірок `0x010F`), `0x0332 × 12` (модель `ESM-48100U2`) та `0x0340 × 10` (серійний номер) — усе це автоматично транслюється в другий порт `PCS-485` (при `DIP2 = OFF`) для зовнішнього моніторингу.
3. **Агрегація банку:** зводить дані активних модулів:
   - Напруга — середня по банку;
   - Струм — сумарний;
   - SOC — середній;
   - SOH — **найгірший (мінімальний) серед модулів**;
   - Комірки та температури — абсолютні екстремуми банку.
4. **Синхронізоване формування потоку CAN (~1.1 с, Deye PCS CAN V3.3 / `DY001`):** кадри `0x351`, `0x355`, `0x356`, `0x359` (Tables 1–7), `0x35C`, `0x35E` (`"DY001"`), `0x361`, `0x363`, `0x364`, `0x371` та per-pack телеметрія (`0x110+i`, `0x150+i`, `0x200+i`, `0x400+i`, `0x500+i`, `0x600+i`, `0x650+i`) транслюються інвертору **суворо після завершення опитування та агрегації обох модулів**, що усуває стрибки лімітів струму й дозволяє Deye бачити кожен модуль окремо. Приймається також heartbeat інвертора `0x305`.
5. **Багаторівневий захист (Safety):**
   - **Тейпер заряду:** плавне лінійне зниження дозволеного струму заряду (CCL) від `3450 мВ` з відсічкою на `3560 мВ` (`DIP1=OFF`), `3455 мВ` (`DIP1=ON`) або `3600 мВ` (`DIP5=ON` / баланс-сесія);
   - **Захист від перерозряду:** обмеження або повне відсікання розряду (DCL = 0) при падінні найслабшої комірки нижче 2.800–2.650 В;
   - **Фізична перехресна верифікація (Cross-Validation):** прапорці Cell OV, Pack OV, Cell UV у кадрі 0x359 активуються тільки за умови збігу біта аварії BMS з реальними вимірами (Cell OV $\ge 3600$ мВ, Pack OV $\ge 54.5$ В, Cell UV $\le 2800$ мВ), що виключає хибні аварійні відключення інвертора;
   - **Зимовий захист без знеструмлення будинку:** при $T < +2\ ^\circ\text{C}$ блокується заряд літію (`CCL = 0 А`, `0x35C` Charge Enable = 0), але біт UT у 0x359 не виставляється, дозволяючи будинку безпечно живитися від АКБ у морози (до $-20\ ^\circ\text{C}$);
   - **Deye Off-Grid Workaround:** при забороні розряду в кадрі 0x355 передається `SOC = 0%`, що змушує Deye гарантовано припиняти розряд навіть в автономному режимі;
   - **Чесний Fail-Closed:** якщо зв'язок з батареями зникає довше ніж на 5 секунд, ліміти струмів скидаються в 0 А, прапорці 0x35C скидаються в 0x00, інвертор безпечно зупиняє роботу банку.

**Керування перемикачами на корпусі (DIP):**
- **DIP1 (SW1, PB12)** — верхня межа напруги заряду (працює, коли `DIP5 = OFF`):
  - *OFF* → 100% (`53.5 В`, номінальний заряд Huawei ESM, стоп `3560 мВ`, дозаряд `3380 мВ`) з інтелектуальним рушієм вирівнювання комірок;
  - *ON* → 90% (`51.8 В`, м'який консервативний режим, стоп `3455 мВ`, дозаряд `3350 мВ`).
- **DIP2 (SW2, PB13)** — режим діагностичного роз'єму інвертора (PCS-485, UART4):
  - *OFF* (штатний режим) → пасивне дзеркало обміну коробка ↔ BMS (дозволяє підключити USB-UART і бачити весь трафік без розриву лінії);
  - *ON* → дослідницький тестовий режим мосту.
- **DIP4 (SW4, PB15)** — базовий ліміт струму заряду на один модуль:
  - *OFF* → `50 А` на модуль (`100 А` на 2 модулі);
  - *ON* → `15 А` на модуль (`30 А` на 2 модулі, штатний 0.15C Huawei).
- **DIP5 (SW5, PC6)** — примусове вирівнювання/балансування (має пріоритет над `DIP1`):
  - *OFF* → керується `DIP1` (`53.5 В` або `51.8 В`);
  - *ON* → `54.0 В` (стоп `3600 мВ`, режим вирівнювання/балансування Huawei).
- Зміна положення DIP-перемикачів зчитується кожні 250 мс з дебаунсом без потреби перезавантажувати пристрій.

## 2. Апаратура: роз'єми, піни та індикація

### 2.1. Зовнішні роз'єми корпусу COM-Box

| Роз'єм | Призначення | Розпіновка (RJ45, піни 1..8) | Параметри лінії |
|---|---|---|---|
| **BMS-485** | Підключення до шини акумуляторів Huawei ESM | **Пін 1**: GND<br>**Пін 5**: RS485-B (Data−)<br>**Пін 6**: RS485-A (Data+)<br>*(інші піни NC)* | Modbus RTU, **9600 8N1**, авто-напрямок |
| **PCS-CAN** | Підключення до CAN-порту інвертора Deye (BMS CAN) | **Пін 1**: GND<br>**Пін 7**: CAN-L<br>**Пін 8**: CAN-H<br>*(інші піни NC)* | Deye PCS CAN V3.3 (`DY001`), **500 кбіт/с**, ~1 Гц |
| **PCS-485** | Діагностичний порт (UART4) | **Пін 1**: GND<br>**Пін 5**: RS485-B (Data−)<br>**Пін 6**: RS485-A (Data+)<br>*(інші піни NC)* | Modbus RTU, **9600 8N1**, дзеркало при DIP2 OFF |
| **Power (B+ / B−)** | Гвинтовий клемник живлення COM-Box від батарейного банку | **B+**: +15…+60 В DC (через запобіжник)<br>**B−**: GND (мінус батареї) | Споживання плати < 0.5 Вт |

> ℹ️ **Гальванічна ізоляція:** трансивер `CA-IS3080WX` на порту `BMS-485` має повну гальванічну ізоляцію, тому силова земля/корпус акумулятора з плаваючим потенціалом до клеми `GND` не підключається.

### 2.2. Підключення до порту COM батарей Huawei ESM (RJ45)

Згідно з офіційною документацією Huawei ESM (Table 3-74), порт `COM` має контакти `1 (T+)`, `2 (T−)`, `4 (R+)`, `5 (R−)`, `7 (CANH)`, `8 (CANL)`. Проте на реальному обладнанні **Huawei ESM-48100U2** зв'язок по 2-провідній шині RS485 (Half-Duplex) працює **виключно по пінах 1 і 2** (об'єднання 1+4 та 2+5 садить шину).

**Схема адаптерного кабелю `COM-Box (BMS-485) ↔ Huawei ESM (COM_IN)`:**

| Сигнал лінії | Пін RJ45 (з боку COM-Box) | Пін RJ45 (з боку Huawei `COM_IN`) | Принцип з'єднання |
|---|---|---|---|
| **Data+ (RS485-A)** | **Пін 6** | **Пін 1 (`RS485+`)** | Пряме з'єднання (пін 4 не підключати) |
| **Data− (RS485-B)** | **Пін 5** | **Пін 2 (`RS485−`)** | Пряме з'єднання (пін 5 не підключати) |
| **GND / Shield** | *Не підключати* | *Не підключати* | На корпусі/екрані присутній плаваючий потенціал; шина працює диференційно |
| **CANH / CANL** | *Не підключати* (NC) | *Не підключати* (NC) | Піни 7 і 8 коробки не задіювати |

> ⚠️ **Важливо:**  
> 1. **Між коробкою COM-Box і 1-м акумулятором** використовується **виключно адаптерний кабель** за таблицею вище. Прямий кабель 1-в-1 використовувати не можна (пін 1 GND коробки замкне лінію A батареї на землю, а пін 6 потрапить на пустий контакт NC).  
> 2. **Між самими акумуляторами Huawei** (`COM_OUT` попереднього → `COM_IN` наступного) використовується **звичайний стандартний прямий кабель RJ45 (1-в-1)**.  
> 3. На вільному порту `COM_OUT` останнього модуля обов'язково встановлюється **120 Ом CAN-термінатор** (між контактами 7 і 8) для забезпечення апаратної самоадресації блоків.
> 4. **Фізичне узгодження лінії RS485:** плата `COM-Box` має запаяний термінатор `120 Ом` (`R22`) без активного зміщення (fail-safe bias). Для стабільного зв'язку з Huawei на короткій лінії `R22` випаюється або додається зміщення `1–4.7 кОм` (A до ізольованого +VCC, B до ізольованого GND).

## 3. Протокол опитування Huawei ESM (RS485)

### 3.1. Кінцевий автомат опитування (`hw_poll_service`)
Опитування організовано на базі неблокуючого кінцевого автомата для фіксованого банку з **2 адрес** (`0xD6 = 214`, `0xD7 = 215`):
1. **Швидкий цикл (`HW_Q_BASE .. HW_Q_CELL`, ~1.0–1.1 с на весь банк):** для кожного модуля послідовно виконуються 3 ключові запити FC03 з паузою `30 мс` між запитами та `80 мс` між модулями:
   - `0x0000 × 7`: DC-шина, напруга на клемах, знаковий струм, SOC, SOH, екстремуми температур;
   - `0x0042 × 9`: лічильники циклів (`0x0042–0x0043`), відданих А·год (`0x0044–0x0045`) та 5 слів аварій/попереджень (`0x0046–0x004A`);
   - `0x0022 × 15`: напруги 15 комірок (мВ).
2. **Повільний цикл (раз на 5 проходів кожного модуля):** після швидких запитів для поточного модуля додається 1 розширений запит по колу (для моніторингу на `PCS-485`):
   - `0x0012 × 15`: температури 15 комірок (1 °C);
   - `0x0101 × 15`: версії ПЗ/апаратури та кількість комірок (`0x010F`);
   - `0x0332 × 12`: назва моделі (`ESM-48100U2`);
   - `0x0340 × 10`: серійний номер модуля (20 байтів ASCII).
3. **Таймаути та debounce:** таймаут очікування відповіді становить `400 мс` (активний модуль відповідає за `~110–115 мс`). Після 5 пропусків поспіль модуль виключається з поточної агрегації (відновлюється миттєво при появі відповіді).

## 4. Протокол зв'язку з інвертором Deye (CAN)

Передача здійснюється щосекунди (~1 Гц) у стандарті **Deye PCS CAN V3.3 (`DY001`)**:

| ID | DLC | Payload | Опис |
|---|---|---|---|
| **`0x351`** | 8 | `CVL(2) CCL(2) DCL(2) DVL(2)` | Ліміти напруги (0.1 В) та струму (0.1 А, LE). `DVL = 450` (45.0 В) |
| **`0x355`** | 4 | `SOC(2) SOH(2)` | Рівень заряду (%) та здоров'я (%, мінімум по банку) |
| **`0x356`** | 8 | `V(2) I(2) T(2) 0(2)` | Напруга (0.01 В), струм (0.1 А, **розряд +, заряд −**), темп. (0.1 °C) |
| **`0x359`** | 8 | `P0..P3(4) A4..A5(2) E6(1) 0` | Захисти (Tables 1–4), тривоги (Tables 5–6) та системні помилки (Table 7) |
| **`0x35C`** | 8 | `Flags(1) 0(7)` | Байт 0: біт 7 = Charge Enable, біт 6 = Discharge Enable (`0xC0` норма, `0x00` аварія) |
| **`0x35E`** | 8 | `'D''Y''0''0''1' Count Cap(2)` | Ідентифікатор `DY001`, кількість модулів, сумарна ємність (0.1 А·год) |
| **`0x361`–`0x371`** | 8 | `Extremes / Cfg / Counts / Limits` | Мін./макс. напруги й температури, конфіг, лічильники модулів, ліміти |
| **`0x110+i`..`0x650+i`** | 8 | `Per-pack telemetry` | Статус, V/I/SOC/SOH (`0x150+i`), комірки/T (`0x200+i`), цикли (`0x400+i`), FW/модель/SN |

Кадр `0x305` інвертора є вхідним downlink-повідомленням (Heartbeat інвертора); шлюз його приймає в `CAN_FIFO0` для контролю активності інвертора та ніколи не передає в шину.

## 5. Збірка, прошивка та завантаження

### 5.1. Команди збірки PlatformIO
```bash
pio run                          # Збірка обох конфігурацій (standalone та app)
pio run -e genericGD32F305       # Тільки автономний образ (0x08000000)
pio run -e genericGD32F305_app   # Тільки образ під bootloader (0x08004000)
```

- **`genericGD32F305` (standalone):** записується з адреси `0x08000000`, замінюючи заводський bootloader.
- **`genericGD32F305_app`:** записується з адреси `0x08004000`, зберігаючи штатний bootloader. Скрипт [`generate_hex.py`](generate_hex.py) автоматично додає сигнатуру `G5RC` на зміщенні `0x150`.

### 5.2. Прошивка через ST-Link
Підключити програматор ST-Link V2 до роз'єму SWD на платі (GND, SWCLK, SWDIO, 3.3V):
```bash
pio run -t upload
```

## 7. Чек-лист польового введення в експлуатацію

1. [ ] Перевірити правильність підключення ліній RS485 A/B та GND до порту COM акумулятора Huawei ESM.
2. [ ] Переконатися у наявності термінатора 120 Ом на пінах 7/8 останнього порту COM_OUT.
3. [ ] Подати живлення на COM-Box (зелений індикатор Running має засвітитися постійно).
4. [ ] Спостерігати за індикатором BMS-485: після надсилання запиту він має блимати при отриманні валідної відповіді від модуля (адреса 0xD6).
5. [ ] Підключити шину CAN до інвертора Deye, виставити на інверторі `Lithium Mode 00`.
6. [ ] Перевірити на екрані інвертора: відсутність помилки F58, коректний SOC, напругу, кількість модулів (1 або більше).
7. [ ] Перевірити струм під зарядом та розрядом: відсутність хибних стрибків лімітів та коректну роботу захистів.
