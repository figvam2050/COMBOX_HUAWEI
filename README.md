# COM-Box (Huawei ESM) — Прошивка конвертера BMS RS485 → CAN (Deye / Pylontech)

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

> **⚠️ Це окремий спеціалізований проєкт-клон для роботи з акумуляторними батареями Huawei ESM** (ESM-48100A1/B1/B3/U2, ESM-48150B1 тощо).
> Прошивка PlatformIO для мікроконтролера **GD32F305RCT6** (Cortex-M4F, 256K Flash, 96K RAM), яка виконує роль інтелектуального шлюзу та координатора безпеки між акумуляторним банком **Huawei ESM (15S LiFePO4)** та гібридним сонячним інвертором **Deye** (протокол CAN Lithium Mode 00 = Pylontech CAN v2.0.6, 500 кбіт/с).

RS485-бік прошивки реалізує протокол Modbus RTU для швидкісного опитування акумуляторів Huawei ESM (конфігурація для банку з 1 або 2 модулів: адреси `0xD6` = 214 та `0xD7` = 215, динамічна підтримка роботи як з одним, так і з двома блоками, швидка серія з 3-х ключових FC03-запитів телеметрії, аварійні слова `0x0046–0x004A`, по-коміркова телеметрія 15 комірок `0x0022..0x0030`, синхронізована видача в CAN після агрегації).

## Швидкий старт (розробка та збірка)

```bash
git clone https://github.com/figvam2050/COMBOX_HUAWEI.git
```

1. **VS Code:** `File → Open Folder…` → обрати папку `COMBOX_HUAWEI`. Встановіть рекомендоване розширення **PlatformIO IDE** (за пропозицією з [`.vscode/extensions.json`](.vscode/extensions.json)).
2. **Збірка:** у терміналі виконати:
   ```bash
   pio run
   ```
   Обидва варіанти збірки (автономний `genericGD32F305` та `genericGD32F305_app` під заводський завантажувач з міткою `G5RC`) збираються одночасно за один прогін.
3. **Готові бінарні образи:** `compiled_firmware/firmware.bin|.hex` (standalone) та `compiled_firmware_app/` (під bootloader). Прошивка через ST-Link:
   ```bash
   pio run -t upload
   ```
4. **Діагностика шини:**
   - Пасивний RS485-сніфер батарейної лінії: `tools/rs485_sniff.py`
   - Зовнішній CAN-сніфер для ESP32 / Arduino Nano: папка `can_sniffer/`
5. **Еталони знань з правами read-only:** `DEYE_CAN_RS485_BASE.md` та `PORT_MAPPING.md` захищені `chmod 444`. Для редагування: `chmod 644 <файл>` → правка → `chmod 444 <файл>`.

## Хто що: простий опис системи

**Що це за коробка:** COM-Box — це апаратний перекладач та захисний координатор між промисловими акумуляторами Huawei ESM та гібридним інвертором Deye. Акумулятори Huawei розмовляють по шині RS485 протоколом Modbus RTU, а інвертор очікує швидку шину CAN стандарту Pylontech. Коробка забезпечує їхнє узгодження, виконує агрегацію паралельних блоків у єдину віртуальну батарею та захищає акумулятори від аварійних режимів.

**Що прошивка робить автоматично в циклі:**
1. **Самоадресація та виявлення модулів:** батареї Huawei ESM з'єднуються кабелем RJ45 ланцюжком (COM_IN / COM_OUT). На останньому модулі встановлюється штатний CAN-термінатор 120 Ом (піни 7/8). Завдяки цьому модулі автоматично розподіляють адреси `0xD6, 0xD7` (214, 215). Підтримується гаряче підключення та робота як з двома, так і з одним акумулятором.
2. **Опитування телеметрії:** коробка послідовно опитує кожен активний блок швидкою серією з 3-х ключових Modbus FC03-запитів:
   - `0x0000 × 7`: напруга шини, напруга модуля, струм зі знаком, SOC, SOH, екстремуми температур;
   - `0x0046 × 5`: апаратні аварії та попередження;
   - `0x0022 × 15`: точні напруги всіх 15 окремих комірок (у мВ).
3. **Агрегація банку:** зводить дані активних модулів:
   - Напруга — середня по банку;
   - Струм — сумарний;
   - SOC — середній;
   - SOH — **найгірший (мінімальний) серед модулів**;
   - Комірки та температури — абсолютні екстремуми банку.
4. **Синхронізоване формування потоку CAN (~1.1 с):** кадри Pylontech CAN v2.0.6 (0x351, 0x355, 0x356, 0x359, 0x35C, 0x35E) транслюються інвертору **суворо після завершення опитування та агрегації обох модулів**, що усуває стрибки лімітів струму.
5. **Багаторівневий захист (Safety):**
   - **Тейпер заряду:** плавне лінійне зниження дозволеного струму заряду (CCL) при наближенні найвищої комірки до 3.550–3.600 В;
   - **Захист від перерозряду:** обмеження або повне відсікання розряду (DCL = 0) при падінні найслабшої комірки нижче 2.800–2.650 В;
   - **Фізична перехресна верифікація (Cross-Validation):** прапорці Cell OV, Pack OV, Cell UV у кадрі 0x359 активуються тільки за умови збігу біта аварії BMS з реальними вимірами (Cell OV $\ge 3600$ мВ, Pack OV $\ge 54.5$ В, Cell UV $\le 2800$ мВ), що виключає хибні аварійні відключення інвертора;
   - **Зимовий захист без знеструмлення будинку:** при $T < +2\ ^\circ\text{C}$ блокується заряд літію (`CCL = 0 А`, `0x35C` Charge Enable = 0), але біт UT у 0x359 не виставляється, дозволяючи будинку безпечно живитися від АКБ у морози (до $-20\ ^\circ\text{C}$);
   - **Deye Off-Grid Workaround:** при забороні розряду в кадрі 0x355 передається `SOC = 0%`, що змушує Deye гарантовано припиняти розряд навіть в автономному режимі;
   - **Чесний Fail-Closed:** якщо зв'язок з батареями зникає довше ніж на 5 секунд, ліміти струмів скидаються в 0 А, прапорці 0x35C скидаються в 0x00, інвертор безпечно зупиняє роботу банку.

**Керування перемикачами на корпусі (DIP):**
- **DIP1 (SW1, PB12)** — верхня межа напруги заряду:
  - *OFF* → 100% (54.0 В, повний номінальний заряд 15S) з інтелектуальним рушієм вирівнювання комірок: сесії призначаються за станом банку (HIGH $\ge 100$ мВ кожні 24 год, MED $30...100$ мВ кожні 72 год / 3 доби, OK $< 30$ мВ кожні 30 діб, вихід при розкиді $\le 25$ мВ; детальніше див. [`BALANCE_AUTO.md`](BALANCE_AUTO.md));
  - *ON* → 90% (51.8 В, м'який консервативний режим, продовжує ресурс).
- **DIP2 (SW2, PB13)** — режим діагностичного роз'єму інвертора (PCS-485, UART4):
  - *OFF* (штатний режим) → пасивне дзеркало обміну коробка ↔ BMS (дозволяє підключити USB-UART і бачити весь трафік без розриву лінії);
  - *ON* → дослідницький тестовий режим мосту.
- **DIP5 (SW5, PC6)** — базовий ліміт струму заряду на один модуль:
  - *OFF* → 40 А на модуль (80 А на 2 модулі);
  - *ON* → 50 А на модуль (100 А на 2 модулі).
- Зміна положення DIP-перемикачів зчитується кожні 250 мс з дебаунсом без потреби перезавантажувати пристрій.

## ⚡ Огляд системи та технічні характеристики

```
[Батареї Huawei ESM 15S]  <-- RS485 (Modbus RTU 9600 8N1) -->  [ COM-Box ]  <-- CAN (500 kbps, ~1.1 s) -->  [Інвертор Deye]
(адреси 0xD6, 0xD7)                                            (GD32F305)                                     (Lithium Mode 00)
- Кабель RJ45 ланцюжком                                        - FSM опиту 2-х модулів                         - Кадри 0x351..0x35E
- CAN-термінатор 120 Ом (піни 7/8)                             - Синхронна агрегація                           - Heartbeat 0x305
- Підтримка 1 або 2 блоків                                     - Динамічний тейпер струму                      - Fail-closed охорона
```

| Параметр | Значення | Примітка |
|---|---|---|
| Мікроконтролер | **GD32F305RCT6** | Cortex-M4F, 256K Flash, 96K RAM, HSI 8 МГц |
| Батарейна шина (RS485) | **9600 бод, 8N1** | Гальванічно ізольований трансивер CA-IS3080WX (авто-напрямок) |
| Шина інвертора (CAN) | **500 кбіт/с**, стандартні 11-біт кадри | Гальванічно ізольований трансивер ISO1050, синхронно з агрегацією (~1.1 с) |
| Діагностичний порт (PCS-485) | **9600 бод, 8N1** (UART4, PC12/PD2) | Пасивне дзеркало трафіку BMS (DIP2 OFF) |
| Топологія акумуляторів | **15S LiFePO4** (Huawei ESM-48100/48150) | 48.0 В номінал, 54.0 В максимальний заряд |
| Адреси батарей | `0xD6` (214) та `0xD7` (215) | Автоматична адресація через внутрішній CAN-ланцюг, підтримка 1 або 2 АКБ |

## 2. Апаратура: роз'єми, піни та індикація

### 2.1. Зовнішні роз'єми корпусу COM-Box

| Роз'єм | Призначення | Розпіновка (RJ45, піни 1..8) | Параметри лінії |
|---|---|---|---|
| **BMS-485** | Підключення до шини акумуляторів Huawei ESM | **Пін 1**: GND<br>**Пін 5**: RS485-B (Data−)<br>**Пін 6**: RS485-A (Data+)<br>*(інші піни NC)* | Modbus RTU, **9600 8N1**, авто-напрямок |
| **PCS-CAN** | Підключення до CAN-порту інвертора Deye (BMS CAN) | **Пін 1**: GND<br>**Пін 7**: CAN-L<br>**Пін 8**: CAN-H<br>*(інші піни NC)* | Pylontech CAN v2.0.6, **500 кбіт/с**, 1 Гц |
| **PCS-485** | Діагностичний порт (UART4) | **Пін 1**: GND<br>**Пін 5**: RS485-B (Data−)<br>**Пін 6**: RS485-A (Data+)<br>*(інші піни NC)* | Modbus RTU, **9600 8N1**, дзеркало при DIP2 OFF |
| **Power (B+ / B−)** | Гвинтовий клемник живлення COM-Box від батарейного банку | **B+**: +15…+60 В DC (через запобіжник)<br>**B−**: GND (мінус батареї) | Споживання плати < 0.5 Вт |

> ⚠️ **Критично:** Пін 1 (GND) обов'язково має бути підключений спільним проводом на всіх лініях RJ45 для вирівнювання потенціалів ізольованих трансиверів.

### 2.2. Підключення до порту COM батарей Huawei ESM (RJ45)

Згідно з офіційною документацією Huawei ESM (Table 3-74 «Pin definitions of communications ports»), порт `COM` батареї має **4-провідний інтерфейс RS485 (Full-Duplex)**:
* **Пін 1:** `RS485 T+` (Transmission +)
* **Пін 2:** `RS485 T−` (Transmission −)
* **Пін 3:** `NC` (Reserved)
* **Пін 4:** `RS485 R+` (Reception +)
* **Пін 5:** `RS485 R−` (Reception −)
* **Пін 6:** `NC` (Reserved)
* **Пін 7:** `CANH` (внутрішня шина автоадресації між модулями)
* **Пін 8:** `CANL` (внутрішня шина автоадресації між модулями)
* **Екран RJ45 (Shield):** захисне заземлення / сигнальна земля

**Схема адаптерного кабелю `COM-Box (BMS-485) ↔ Huawei ESM (COM_IN)`:**  
Оскільки трансивер COM-Box працює у 2-провідному напівдуплексі (Half-Duplex), лінії передачі та прийому на штекері Huawei об'єднуються:

| Сигнал лінії | Пін RJ45 (з боку COM-Box) | Пін RJ45 (з боку Huawei `COM_IN`) | Принцип з'єднання |
|---|---|---|---|
| **Data+ (RS485-A)** | **Пін 6** | **Пін 1 (`T+`) + Пін 4 (`R+`)** | Запаралелити контакти 1 та 4 |
| **Data− (RS485-B)** | **Пін 5** | **Пін 2 (`T−`) + Пін 5 (`R−`)** | Запаралелити контакти 2 та 5 |
| **GND (Земля)** | **Пін 1** | **Металевий екран RJ45 (Shield)** / PE | Захист від синфазних завад |
| **CANH / CANL** | *Не підключати* (NC) | *Не підключати* (NC) | Піни 7 і 8 коробки не задіювати |

> ⚠️ **Важливо:**  
> 1. **Між коробкою COM-Box і 1-м акумулятором** використовується **виключно адаптерний кабель** за таблицею вище. Прямий кабель 1-в-1 використовувати не можна (пін 1 GND коробки замкне лінію T+ батареї на землю, а пін 6 потрапить на пустий контакт NC).  
> 2. **Між самими акумуляторами Huawei** (`COM_OUT` попереднього → `COM_IN` наступного) використовується **звичайний стандартний прямий кабель RJ45 (1-в-1)**.  
> 3. На вільному порту `COM_OUT` останнього модуля обов'язково встановлюється **120 Ом CAN-термінатор** (між контактами 7 і 8) для забезпечення апаратної самоадресації блоків.

### 2.3. Світлодіодна індикація (LED)

| Світлодіод | Пін MCU | Призначення | Поведінка |

## 3. Протокол опитування Huawei ESM (RS485)

### 3.1. Кінцевий автомат опитування (`hw_poll_service`)
Опитування організовано на базі неблокуючого кінцевого автомата:
1. **Фаза сканування (`HW_POLL_SCAN`):** Раз на 3 секунди виконується фоновий запит-проба `0x0000 × 1` на одну з невідомих адрес із пулу (`0xD6–0xDD, 0xE0–0xE7`). Модулі, що відповіли, додаються до бітової маски активних модулів `hw_present_mask`.
2. **Фаза регулярного опиту (`HW_POLL_QUERY`):** Для кожного відомого модуля по черзі виконується серія цільових запитів FC03 з паузою 30 мс між запитами:
   - `0x0000 × 7`: DC-шина, напруга на клемах, знаковий струм, SOC, SOH, екстремуми температур;
   - `0x000A × 1`: стан модуля (0 Charge … 3 Free);
   - `0x0042 × 2` / `0x0044 × 2`: лічильники циклів та відданих А·год;
   - `0x0046 × 5`: 5 регістрів аварійних слів;
   - `0x010F × 1`: кількість комірок у модулі;
   - `0x0012 × 15`: температури комірок (1 °C);
   - `0x0022 × 15`: напруги комірок (мВ).
3. **Таймаути:** Таймаут очікування відповіді становить 500 мс (активний модуль відповідає за 45–90 мс). Якщо модуль не відповів тричі поспіль, він виключається з поточної агрегації.

## 4. Протокол зв'язку з інвертором Deye (CAN)

Передача здійснюється щосекунди (1 Гц) у стандарті Pylontech CAN v2.0.6:

| ID | DLC | Payload | Опис |
|---|---|---|---|
| **`0x351`** | 8 | `CVL(2) CCL(2) DCL(2) DVL(2)` | Ліміти напруги (0.1 В) та струму (0.1 А, LE). `DVL = 450` (45.0 В) |
| **`0x355`** | 4 | `SOC(2) SOH(2)` | Рівень заряду (%) та здоров'я (%, мінімум по банку) |
| **`0x356`** | 6 | `V(2) I(2) T(2)` | Напруга (0.01 В), струм (0.1 А, **розряд +, заряд −**), темп. (0.1 °C) |
| **`0x359`** | 8 | `Prot(2) Warn(2) Count(1) 'P' 'N' 0` | Аварійні біти захисту/попередження, кількість активних модулів, маркер PN |
| **`0x35C`** | 2 | `Flags(2)` | Байт 0: біт 7 = Charge Enable, біт 6 = Discharge Enable (`0xC0` норма, `0x00` аварія) |
| **`0x35E`** | 8 | `'P' 'Y' 'L' 'O' 'N' 0 0 0` | Ідентифікатор виробника Pylontech |

Кадр `0x305` інвертора є вхідним downlink-повідомленням (Heartbeat інвертора); шлюз його лише приймає та ніколи не передає в шину.

## 5. Збірка, прошивка та завантаження

### 5.1. Команди збірки PlatformIO
```bash
pio run                          # Збірка обох конфігурацій (standalone та app)
pio run -e genericGD32F305       # Тільки автономний образ (0x08000000)
pio run -e genericGD32F305_app   # Тільки образ під bootloader (0x08004000)
```

- **`genericGD32F305` (standalone):** записується з адреси `0x08000000`, замінюючи заводський bootloader.
- **`genericGD32F305_app`:** записується з адреси `0x08004000`, зберігаючи штатний bootloader. Скрипт [`generate_hex.py`](generate_hex.py) автоматично додає сигнатуру `G5RC` на зміщенні `0x150`.

### 5.2. Прошивка через ST-Link
Підключити програматор ST-Link V2 до роз'єму SWD на платі (GND, SWCLK, SWDIO, 3.3V):
```bash
pio run -t upload
```

## 7. Чек-лист польового введення в експлуатацію

1. [ ] Перевірити правильність підключення ліній RS485 A/B та GND до порту COM акумулятора Huawei ESM.
2. [ ] Переконатися у наявності термінатора 120 Ом на пінах 7/8 останнього порту COM_OUT.
3. [ ] Подати живлення на COM-Box (зелений індикатор Running має засвітитися постійно).
4. [ ] Спостерігати за індикатором BMS-485: після надсилання запиту він має блимати при отриманні валідної відповіді від модуля (адреса 0xD6).
5. [ ] Підключити шину CAN до інвертора Deye, виставити на інверторі `Lithium Mode 00`.
6. [ ] Перевірити на екрані інвертора: відсутність помилки F58, коректний SOC, напругу, кількість модулів (1 або більше).
7. [ ] Перевірити струм під зарядом та розрядом: відсутність хибних стрибків лімітів та коректну роботу захистів.
